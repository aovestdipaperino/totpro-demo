What you are looking at

A Totocalcio coupon carried thirteen football matches, each marked 1 for a home win, X for a draw, 2 for an away win. Play every combination and you spend 1,594,323 columns to be certain of one. The trade of the sistemisti was buying a guarantee for less.

The original asked its questions in Italian, one bordered panel at a time, and filtered columns with a hardware key plugged into the user port. This rebuild keeps the screens and the engine, and replaces the disk's reduced systems with the provably smallest one: the perfect ternary Hamming code of length thirteen.

The screens are translated by default. Switch to Italiano for the prompts as the 1984 binary printed them, transcribed rather than rewritten.

Try the perfect system

  1. Type 13 then RETURN for the match count.
  2. Answer N then RETURN to skip the team list.
  3. On the grid, press 1 X 2 then ↓ for each of the thirteen rows: every match a triple.
  4. Press RETURN, then Y RETURN to confirm.
  5. Answer N RETURN six times to decline the conditioning filters, then RETURN twice.

ESC steps back a screen whenever you want a different answer.

The totals report 59,049 columns and a guaranteed twelve. Go back with ESC and accept the first filter instead: TAB and + − set the bounds, and the system shrinks. That is the moment the guarantee quietly stops holding.

Rust, ratatui and a hand-written DOM backend, in one file with the WebAssembly inlined. Nothing is uploaded: the coupon stays in your browser.
